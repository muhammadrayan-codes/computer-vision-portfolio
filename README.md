### 2. Calibrated Selective Identity Association for Open-World Person Re-ID

A Computer Vision research project investigating reliable identity association in open-world Person Re-ID using a three-way MATCH / DEFER / UNKNOWN framework.

**Key Areas:**
- Person Re-ID
- Open-world recognition
- Selective prediction
- Model calibration
- Similarity margin
- Gallery ambiguity
- Track-level temporal consistency

**Results:**
- Market-1501: 99.12% accuracy at 83.0% coverage
- PETS09: 99.45% accuracy at 59.0% coverage
